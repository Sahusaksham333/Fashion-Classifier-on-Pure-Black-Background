# Fashion-MNIST Classifier (Streamlit)

1. Put `fashion-mnist_train.csv` and `fashion-mnist_test.csv` in `input/` (or next to the scripts).
2. `pip install -r requirements.txt`
3. `python train_model.py`   # trains the CNN, writes fashion_cnn.keras + metrics.json (~10 min on CPU)
4. `streamlit run app.py`
